# richardlwh.github.io

Personal website, served by GitHub Pages from the `main` branch. Plain HTML and CSS, no build step.

## Editing

- `index.html`: all content. Search for `PLACEHOLDER` to find the spots still to fill in
  (photo, research interests, CV PDF, paper draft link).
- `style.css`: layout and colors (light and dark).
- `assets/`: put `photo.jpg`, `cv.pdf` and paper PDFs here.

Publish with `git add -A && git commit -m "Update" && git push`; the site refreshes within a minute or two.
